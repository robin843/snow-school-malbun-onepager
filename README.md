# snow-school-malbun-onepager

Erstelle einen one-pager für die Skischule Malbun. das erste bild gerne als Hero.  Der kunde mag diese Balken im zweiten Foto von der Broschüre, ist aber offen für neue Designs. 
Das ist das Logo noch im vierten.  Und als letztes das klassische Skischulewappen von Malbun.

Diese Seiten sollte es beinhalten. 

•⁠  ⁠Preise für Ski und Snowboardkurse (Privatkurse, Gruppenkurse, Samstagskurse)
•⁠  ⁠Button für die Direktbuchung über unser Skischulsystem
•⁠  ⁠Über uns (Skischulleitung und Team)
•⁠  ⁠Jobs
•⁠  ⁠Kontakt und Standort
•⁠  ⁠Infos mit AGB's, FAQ's, etc.
